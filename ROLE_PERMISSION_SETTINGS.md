# Ayo Bangun.ID Contractor - Dynamic Role Settings

## Owner
Akses penuh:
- perusahaan
- proyek
- user & password
- role permission
- material master
- stok
- progress
- laporan
- WhatsApp report
- Firebase configuration

Default:
owner / owner123

## Admin
Akses:
- kelola mandor
- master material
- verifikasi stok
- laporan
- edit data operasional

Default:
admin / 0000

## Mandor
Akses lapangan:
- absensi tenaga kerja
- penggunaan material
- stok opname
- progress pekerjaan
- kendala lapangan
- dokumentasi

Contoh:
mandor1 / 1111

## Permission Model
Setiap user memiliki:
- role
- projectAccess
- permissions

Data dipisahkan berdasarkan project_id agar multi proyek aman.
